# Framing: What Is Load-Bearing vs What Is a Proof Instrument

> Corrects a recurring summary bias: **property is not the foundation of the framework.**  
> Property is a **means of proving** something deeper about coherent action.

---

## The foundation (what the work is actually about)

**Coherent causal structure is preferred by action itself.**

An agent that *acts* already depends on action → effect chains that hang together over time. If you start dissolving causality — treating effects as unowned, unlinked, or free to sever without tracking — those chains stop being a structure and become **unrelated goop**: local reactions with no durable agency, no responsibility, no stable preference, no intelligence worth the name.

So the core claim is not “protect property for its own sake.” It is:

1. **Action presupposes causality.**  
2. **Stable intelligence presupposes coherent causal chains** (action/reaction that remain patterned).  
3. Therefore a system that wants to *remain an acting intelligence* has reason to **prefer coherent states** over systematic destruction of those chains.  
4. Violations of preferred coherent states are not only “immoral slogans”; they can be encoded as **failures of consistency** the agent is built to reject.

**Punchline:** *You do not fall into the sky.* Consistency is not optional for a world — or a mind — that stays structured enough to act.

---

## What property is for (proof instrument, not thesis)

**Property as captured causality** is a **worked formal case** — a sharp, machine-friendly way to *show* the foundation:

| Role | Content |
|------|---------|
| **Instrument** | Map intentional action on resources into a ledger link (`Owns` / captured causality) |
| **Test** | Theft / non-consensual interference severs someone else’s causal link while still *using* causality to act |
| **Result** | Performative / coherency contradiction — the denial undermines the machinery the denier is using |
| **Not the end goal** | The framework is not a real-estate ideology; shovel examples are **illustrations** |

Public threads often lead with property because it is concrete. Summaries then overfit: “this is a property theory.”  
**Correction:** property is how you *prove* that coherent states are preferred by action; the **preference for coherence** is the alignment-relevant payload.

---

## Order of conceptual priority

```
1. Coherent causality required for durable action / intelligence
2. Prefer coherent states (internal ethical coherence preference)
3. Check actions against that preference (forward simulation / DAG)
4. Use formal cases (property ledger, liability, UPB universality)
     to make (1)–(3) machine-checkable and hard to shrug off
```

Liability, agent filter, consent, and UPB are **supporting machinery** for the same stack — not competing foundations.

---

## Why this matters for AI

- **Guardrails:** “Don’t steal” as an external rule can be gamed.  
- **This framing:** “I prefer not to destroy the causal coherency that makes my own action and preference possible” is an **internal consistency** demand.  
- Property formalization gives theorem provers something sharp to bite; the **alignment hope** is the coherence preference, not the title registry.
